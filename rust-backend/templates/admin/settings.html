How to allow public image access on your S3 Bucket (Click to view AWS Bucket Policy)

If images show as broken (HTTP 403 Access Denied), AWS S3 is blocking public reads by default. You can either select "Auto-Presigned URLs" above, or add this policy to AWS:

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::{{ settings.storage_s3_bucket | default(value='your-bucket-name') }}/*"
        }
    ]
}
