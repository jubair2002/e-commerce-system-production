CSV Column Reference
Column Header Required Description

sku Recommended Unique Stock Keeping Unit
product_type Optional simple or variable / Products with option
category Optional Category name (auto-assigned or created)
stock Optional Initial inventory count (default: 0)

color Optional Comma-separated colors for variants
size Optional Comma-separated sizes for variants
model Optional Comma-separated model compatibility
short_description Optional Brief catalog summary snippet
description Optional Full HTML or text description
brand Optional Manufacturer or brand name
tags Optional Search tags separated by comma
status Optional active, draft, or inactive
featured Optional 1 to feature on homepage, 0 otherwise
